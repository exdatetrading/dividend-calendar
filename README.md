# Dividend Calendar — Telegram

Бесплатный публичный календарь и рассылка через Telegram-бота **@Dividend_notification_bot**.

## Публикация сайта

1. На GitHub под аккаунтом `mariabrownrr-cell` создайте **публичный** репозиторий `dividend-calendar`.
2. Загрузите в него **содержимое** этого архива (включая папку `.github`), а не сам ZIP.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. После публикации сайт будет доступен по адресу `https://mariabrownrr-cell.github.io/dividend-calendar/`.
5. В @BotFather используйте `/setmenubutton` → выберите `@Dividend_notification_bot` → текст `Календарь` → вставьте адрес опубликованного сайта.

## Бесплатная рассылка в Telegram-канал

1. Создайте канал и добавьте `@Dividend_notification_bot` администратором с правом публиковать сообщения.
2. В GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret добавьте:
   - `TELEGRAM_BOT_TOKEN`: токен из BotFather (никому не публиковать).
   - `TELEGRAM_CHAT_ID`: `@username_канала` для **публичного** канала. Для приватного нужен числовой ID канала.
3. Отредактируйте `trades.json`: добавляйте только **проверенные** сделки, `approved: true` включает отправку.
4. В Actions разрешите выполнение workflow. Можно запустить `Dividend notifications` вручную для теста **в 09:00 по Нью-Йорку**.

Пример сделки (пример структуры, **не подтверждённая реальная сделка**):

```json
{
  "trades": [
    {
      "ticker": "EXAMPLE",
      "open_date": "2026-11-05",
      "ex_date": "2026-11-06",
      "close_date": "2026-11-06",
      "open_before": "16:00",
      "close_after": "09:30",
      "approved": false
    }
  ]
}
```

**Важное:** GitHub Actions может запускаться с задержкой или пропускать запуски; точная доставка в 09:00 не гарантируется. Рассылка предназначена для информирования, не для срочных торговых команд. Публичные GitHub-репозитории могут автоматически отключать расписание после длительной неактивности. Для персональных сообщений каждому клиенту потребуется отдельная база подписчиков; эта версия отправляет в **канал**. Содержимое `data.json` — предварительный календарь; оно не является автоматически проверенными биржевыми данными.
